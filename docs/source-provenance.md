# Source provenance and output evidence

Source: [mohan-li/TP-CLAP](https://github.com/mohan-li/TP-CLAP) commit `39455a4fe4710e27eedf53a5598a6ae6404d0382`, Apache-2.0. `configuration_tp_clap.py`, `modeling_tp_clap.py`, and `fusion.py` were copied into `src/tpclap_infer/_impl/`. `modeling_tp_clap.py` changes only backbone construction: pinned config-only initialization replaces `from_pretrained` base-weight downloads; TP-CLAP's own checkpoint still loads strictly. The package adds its own small audio/text adapter and does not carry upstream training, datasets, evaluation tasks or metrics.

Author checkpoints: [mohanli/TP-CLAP](https://huggingface.co/mohanli/TP-CLAP), revision `b14090f5210715958f5ab7056d3c47f5f61cb582`, model card Apache-2.0. CED config/model code/frontend: `mispeech/ced-base` revision `db3e14a8db4c21b56b165261c39649741a900e7f`. BERT config/tokenizer: `google-bert/bert-base-uncased` revision `86b5e0934494bd15c9632b12f734a8a67f723594`. Exact file hashes are in `src/tpclap_infer/config/checkpoints.toml`. Neither auxiliary backbone weight file is downloaded.

Fixtures under `tests/fixtures` were recorded using the unmodified author model before extraction: NSynth (two 4 s clips, one containing genuine silence) and MagnaTagATune (one 10 s clip with genuine silence). Each records plain audio, conditioned audio, text embeddings and scores. The JSON records Torch, Transformers, NumPy, checkpoint hash and prompt. The audio fixture is nontrivial; baseline embeddings are nonzero and distinct. Float parity applies to the recorded CPU runtime; outside it tests use documented numerical tolerance. This is implementation parity, not model accuracy on music retrieval.

On 2026-11-13 the extracted package was also compared directly with the author's model on two 10-second, 16 kHz Rytho loop preview WAVs under the same CPU runtime, using the MTT checkpoint and the instrument question. Plain and conditioned embeddings both matched exactly (`max abs = 0`, relative difference `0`). These previews stay in local scratch space and are not distributed with the package; the portable synthetic fixtures above remain the regression gate.

Input and output trace: `session._audio` validates 16 kHz and profile length, then invokes the author's CED feature extractor. Plain audio uses CED features, mean over CED tokens and the audio projector. Text uses BERT token masking/mean pooling and text projector. Prompted audio uses CED and BERT token sequences, fusion attention and a separate projector. Each head L2-normalizes. `similarity` returns cosine scores on those vectors. Results describe only the supplied exact-length window; there is no timestamp or implied whole-song coverage. See `session.semantics()`.
